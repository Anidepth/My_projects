# Fish & Accessories Store 🐠

A fish and accessories store web application with user and admin functionality.

## Features

- **Beautiful Split-Screen Login Page** with sliding animation
- **User/Admin Login System**
- **Product Catalog** with natural images
- **Responsive Design** for all devices
- **Add to Cart** functionality
- **Admin Dashboard** to manage products

## Files

- `index.html` - Main landing page with products
- `login.html` - Animated login/signup page (HTML only)
- `login.php` - Login page with PHP authentication
- `styles.css` - All styling
- `script.js` - JavaScript functionality
- `config.php` - Database configuration
- `setup.sql` - Database setup script
- `user-dashboard.php` - User dashboard
- `admin-dashboard.php` - Admin dashboard
- `logout.php` - Logout handler

## Setup

1. Start XAMPP (Apache + MySQL)
2. Copy folder to `C:\xampp\htdocs\fish-accessories-store`
3. Open phpMyAdmin and run `setup.sql`
4. Visit `http://localhost/fish-accessories-store/`
